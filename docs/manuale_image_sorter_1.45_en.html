User manual

Image Sorter

Image, video and PDF viewer and sorter for Linux. Browse your photos quickly and sort them into destination folders with a single key — from the keyboard, the mouse, or a physical Stream Deck.

Installation // download and first run

Image Sorter is a Python application for Linux. The source code and published releases of the project are available on GitHub under a Creative Commons license.

Source code

The project is hosted on GitHub. You can download the full repository, or use the Git command to get an updatable local copy.

Python environment

Running the program requires a Python environment compatible with the program version and the libraries listed in the project.

Two equivalent ways to get the code — they're alternatives to each other, not steps in sequence: either step 1a OR step 1b is enough, not both. From there on (step 2 onward) the process is identical either way.

1a. Download ZIP, no Git needed // simplest, no requirements

The official Image Sorter repository is available at:

GitHub https://github.com/orionriggers/Image-Sorter

From the GitHub page you can choose Code → Download ZIP to download a copy of the project without using Git.

The download produces a file called Image-Sorter-main.zip: it needs to be extracted before the program can be used (right-click the file → "Extract Here" in most file managers). Extracting it creates a folder named Image-Sorter-main — a different name from the repository itself, because GitHub always appends the branch name (main) to the folder name for archives downloaded this way, as opposed to a Git clone.

A terminal in the right folder anyone not comfortable with the command line can open a terminal already positioned inside the extracted folder without typing any cd: in most file managers (Nautilus, Nemo, Thunar, Dolphin...) right-clicking an empty spot in the folder shows an "Open Terminal Here" entry (wording varies slightly by file manager).

1b. Clone with Git, alternative to 1a // recommended if you'll update often

If Git is installed on the computer, the repository can be cloned directly from the terminal — an alternative to the ZIP download in step 1a above, not an extra step after it.

Terminal git clone https://github.com/orionriggers/Image-Sorter.git

After downloading, enter the project folder:

Terminal cd Image-Sorter

The Git method is especially useful if the program is updated frequently, since it lets you later pull the changes published to the repository.

2. Prepare Python // runtime environment

You need Python 3.8 or later (already present by default on most recent Linux distributions) and a few libraries. The simplest way, run from inside the project folder (the one containing image_sorter.py), is the included install script:

Terminal bash installa.sh

It automatically detects the distribution (apt on Debian/Ubuntu/Mint, dnf on Fedora, pacman on Arch, zypper on openSUSE) and installs everything needed: system packages (tkinter, Pillow's image support, ffmpeg for video previews, poppler for PDFs, hidapi for the Stream Deck, xclip for file copy/paste), the Python libraries via pip, the icon, the application-menu entry and a Desktop shortcut (see the box below), the right-click integration in the file manager (Nemo, Thunar, Dolphin), and — asking on screen — the daemon that keeps the physical Stream Deck active even while the program is closed. It can be re-run at any time, even after an update, with no side effects.

Desktop icon bash installa.sh sets up everything needed to launch Image Sorter like any other program, with no terminal involved: a clickable icon on the Desktop, and an entry in the desktop environment's application menu, searchable by name like any other installed app. If the file manager asks once whether to "trust" the Desktop icon before running it, that's normal (some desktop environments ask this for any new shortcut, not just Image Sorter's) — it happens at most once.

Anyone who chose the manual library installation below doesn't get the icon or menu entry: to get them anyway, without reinstalling anything, just run bash installa.sh afterwards — already-installed libraries are detected and skipped, it only takes care of the icon, menu entry and shortcut.

Installing the libraries manually // alternative to installa.sh

If you'd rather not run the script (or you're on a distribution it doesn't cover), the Python libraries can be installed with pip. Only Pillow is mandatory — without it the program won't even start; every other library is optional and, if missing, only disables the single feature it powers, everything else keeps working.

3. Start Image Sorter // first run

Once the project is downloaded and the Python environment is ready, the program can be started from the terminal by running the project's main script.

Example python3 image_sorter.py

Passing it a path opens that file directly, or, with the --browser option, opens that folder in the folder browser (Naviga) instead of the viewer:

Examples python3 image_sorter.py /path/to/image.jpg
python3 image_sorter.py --browser /path/to/folder

4. Update the program // only if you chose 1b

If the project was installed via git clone (step 1b), updates can be pulled from the repository with:

Terminal git pull

Before updating, it's a good idea to close Image Sorter and, if local changes were made to the project files, to check the repository status to avoid conflicts.

Anyone who downloaded the ZIP (step 1a) has no local repository to pull updates from: to update, just download the ZIP again from the same GitHub page and extract it, replacing the previous folder (or extract it elsewhere and re-run installa.sh from the new folder).

Simple method to get a copy of the project without setting up Git.

Git clone

Better suited to those who want to keep the project updatable.

Viewer // main window

The screen that opens on startup: shows one file at a time (image, video, or PDF page) with the toolbar at the top and the sorting presets on the right.

Navigation

Arrow keys ← → for the next/previous file, mouse wheel, ↑ ↓ for the pages of a multi-page PDF.

Zoom and fit

+ / - to zoom, Z to fit the canvas, X for the original size (1:1).

Editing

Non-destructive rotation, resizing, and interactive cropping with a rule-of-thirds grid and aspect-ratio lock — including the exact ratio of the original — always with Ctrl+Z undo and history.

One-key sorting

With the Sidebar or the Deck window open, keys 1-9 and 0 also move the file to the active preset (shown on the right), while Ctrl+1–9/0 copies it instead of moving it.

Trash with history

Del twice (or Del+Enter) to trash with confirmation — always reversible from History via a temporary, customizable folder: never a direct deletion.

Info overlays

EXIF-info key I for EXIF metadata (bottom left), Ctrl+F for rating and colorlabel (bottom right) — overlaid on the image, without opening other windows.

Compare mode

"Confronta" button (or key W): places two smaller previews next to the main image, previous and next, which follow navigation on their own — view-only, handy for a quick before/after. See the dedicated section below.

Text tags

Every file can have free-form tags besides stars and colors — a dedicated window with Ctrl+T.

Toolbar the buttons at the top give quick access to EXIF Info, choosing a Rating/Flag, Tag, the original size, Compare, Naviga (Browse), Timeline, History and Settings — the same functions are also reachable with keyboard shortcuts.

Sidebar opens the side panel — cycling between inline next to the image, a separate window, or closed; S-Deck switches the physical Stream Deck (if connected) between operational functions and presets, while Deck cycles open one, two, or N presets in a floating window.

Core workflow // the daily loop

Image Sorter is built for a fast loop: open a source folder, judge one file at a time, pick a destination, and move immediately to the next.

① Open a source

Press O or use Naviga (Browse) to pick a folder.

② Judge

View images, videos and PDFs; use zoom, fit and info overlays.

③ Quick compare

Confronta (Compare) splits the screen into 3 columns, for a faster check across a sequence of similar images.

④ Sort

1–9 and 0 move the file to the active preset.
Ctrl+number copies it to the active preset instead.

Keep going

After sorting, the program moves on to the next file.

Opening a source // O

The O shortcut opens the folder browser (Naviga). If the browser is already open, the command brings it to the front, or closes it if it's already active. Picking a new source rebuilds the file list and starts over from the first item.

Quick sorting // numbers 1–9 and 0

The numbers correspond to the destination presets. Pressing a number moves the file to the associated destination; Ctrl+number copies it, leaving the original intact. This requires the Sidebar or the Deck window to be active.

Undoing a move // Ctrl+←

Ctrl+← undoes the last move and restores the file to its source folder.

Safe trash // double Del

Pressing Del twice, or Del + Enter, moves the file to a transit folder instead of deleting it directly. It stays recoverable from History until the transit folder is emptied.

With Ctrl + Del, the image just before the one currently shown is deleted without asking for confirmation; this doesn't apply to the first image in a folder.

Navigation & display // quick controls

Previous and next file // ← →

The ← and → arrows move through the file sequence. Navigation wraps around.

Multi-page PDF // ↑ ↓ · M

On a multi-page PDF, ↑ and ↓ change page without changing file; M shows or hides the strip of page thumbnails, with a slider to jump straight to a specific page.

Mouse wheel // smart behaviour

At normal zoom the wheel changes file; once the image is zoomed in, the wheel pans the image instead. This avoids accidental advancing while looking at a detail (disabled in Compare mode).

Zoom and pan // + − Z X

+ and − change the zoom level; Z fits the canvas; X shows the image at 1:1. Above zoom level 1 the image can be dragged. Ctrl+wheel also zooms.

Fullscreen // F · Enter · H

F toggles fullscreen for images; Enter handles fullscreen for images and the external player for videos/PDFs; H shows or hides the top bar.

Compare // W

W splits the main window into three columns, making it easier to compare 3 adjacent images; the image in the center column can be zoomed with + and −, or Ctrl+mouse wheel.

With Ctrl + Del, the previous image — shown in the left column — is deleted without asking for confirmation.

Editing a file // context menu

The image's context menu gathers the editing, opening and management operations for the current file.

Ritaglia (Crop)

Opens the interactive crop overlay.

Ridimensiona (Resize)

Opens the panel for managing crop dimensions and aspect ratio.

Rinomina (Rename)

Edits the file name directly in the interface.

Ruota (Rotate)

Rotates 90° clockwise or counter-clockwise and saves the image.

Modifica con.. (Edit with..)

Lets you choose the default editing program, which is remembered from then on.

Rating e ColorFlag

Immediate view and edit of a rating or a colored label.

Interactive crop // Crop Overlay

Cropping happens directly on the image through an interactive selection. The area is kept within the bounds of the original, and a selection that is too small is rejected.

When the crop overwrites the original, a backup is created to allow recovery; if you save under a new name the original stays untouched.

Aspect ratio

Manage the height/width ratio of the image, free-form or with preset values.

Remember size

Keeps the crop area's dimensions between sessions.

Magnet

Automatic snapping of the crop line.

Ritaglia (Crop)

Overwrites or renames the file, with a confirmation dialog.

Ritaglia e avanza (Crop and advance)

No confirmation is asked; moves to the next image, closing the crop window.

Ritaglia prossimo (Crop next)

No confirmation is asked; moves to the next image keeping the same crop settings active.

Magnet While cropping, moving a handle close to a guide line (rule-of-thirds grid, image edge, center) snaps it there automatically within a small tolerance distance, making precise, aligned crops easier without manual pixel-perfect positioning. Can be turned off for free control of the crop. Holding Shift while dragging inverts the active mode.

Naviga // folder browser

A grid of thumbnails to scan an entire folder at a glance, with a folder tree on the left and a preview of the selected image on the right. Opens with O or B, or from the "Naviga" button in the toolbar.

Powerful tools for navigating folders and files, filtering and search, previews, assigning Label and Rating — including to a multi-selection of images — and direct sending to the primary Preset.

Two other important, complementary features are reachable from this window: Folder analysis and Duplicate check.

Browse folders

Familiar navigation commands, plus creating a new folder (Ctrl+N) and quickly reaching the main folders. In the thumbnail grid, besides the arrow keys, PageUp/PageDown jump one screen at a time, and Home/End go to the first/last file.

Favorites []

Stores up to 3 favorite folders by clicking the [] button with a folder selected in the right-hand tree column.

Three thumbnail views

Griglia / Vista / Elenco (Grid / View / List) cycles the display type in the central pane.

Sorting and filtering

By name, size, date, or EXIF shot date; a text filter by file name, plus a dedicated filter for minimum Rating and ColorLabel.

Multi-selection

Click, Ctrl+click, Shift+click for ranges, Ctrl+A for everything — with batch operations over the whole selection.

Rating/Flag checkbox

Hides/shows the row of stars and ColorLabel under the thumbnails, for a cleaner grid if preferred — the choice is remembered across sessions.

Copy, cut and paste

Ctrl+C/X/V behave like a real file manager: pasting a copy in the same folder creates a new file instead of doing nothing, and cutting+pasting in the same folder has no effect.

Folder color

Right-click a folder in the tree or the grid → "Colore" (Color) entry: the same 5 colors as the file ColorLabels, shown as squares side by side, applicable and removable per folder. The color shows up as a colored border and text in the icon grid, as colored text in list view, and as the node color in the tree — Privacy always takes visual precedence.

Folder analysis // a chart says more than numbers

The slices show the relative size of each folder's content, making it immediately obvious which folders take up the most space.

Right-click a slice to jump straight to the folder it represents.

Duplicate check // find duplicate files

Three interfaces for finding duplicate files: the most precise one with an exact SHA256 check, a faster one comparing name and size directly, and a summary that reasons per folder instead of per file.


A-B compare Two folders analyzed side by side.

Folder summary // duplicates reasoned per folder

A fourth tab that summarizes the duplicates found at the folder level instead of the single-file level: folders with the most internal duplicates, folders with near-identical content, folders that are entirely duplicated elsewhere, and folders sharing the same name in different places in the tree.

When an entire folder substructure (a folder together with all its subfolders) is duplicated elsewhere, it's reported as a single block with a plain-language sentence — for example "Photos (+8 subfolders) is nearly identical to Backup/Photos — 94% average similarity, 2.1 GB recoverable" — sorted by recoverable space, with an expandable detail per block. From the right-click menu on a block: "Keep one side, trash the other".

Timeline // chronological view + GPS map

Recursively scans one or more folders and organizes the files by date, with filters for year, place, folder, rating and color. Opens with T.

Recursive scan

Add one or more source folders and press "Scansiona" (Scan) — configurable search depth, unlimited by default.

GPS map

Opens an interactive map with every file that has GPS coordinates in its EXIF data, to revisit a trip by place instead of by date.

Sidebar filters

By year, folder, rating and color — with live counts for each entry, click to filter the view.

Two thumbnail sizes

1x / 2x — unlike Naviga, there's more horizontal space here, so the stars and dots are proportionally larger.

Preset, Rating and Tag

As in Naviga, the matching checkboxes show, at the bottom of the window, the row of destination presets and the row of existing tags, to apply them to the current selection.

Preview panel

With the enlarged preview open on the right, a row with stars, the file name and ColorLabel appears below the image — as in Naviga, it updates on every selection change.

History & recovery // safe operations

History keeps track of recent operations and is used to make moves and transit-trash operations recoverable.

Transit trash Deleted files aren't removed directly: they stay in a transit folder until emptying is confirmed.

Settings // seven tabs

The central configuration panel, organized into seven tabs along the top of the window. Opens with R, and remembers the last tab that was open.

Preset // list and management

The heart of the application is the list of configured presets: complete groups of ten destinations, one per key 0-9. From here you create new presets, with the option to copy, rename or delete them, and choose which one is the active primary preset (marked with *). At the bottom, appearance options for the Deck panel (number of columns) and for the Sidebar (assigned preset, fixed/window mode, grid/list appearance).

Destinazioni (Destinations) // folders per key

Here you assign a folder and a label to each of the ten keys (0-9) of the preset selected above. For each key: a name field, a path field (read-only until "percorso libero" / free path is chosen), and a button to browse the disk's folders.

Drag & drop you can drag a folder directly from an external file manager (Nemo, Nautilus, Thunar...) onto a key's colored badge or name field, to assign it as a destination without opening the picker — the label fills itself in from the folder name if the field was empty. Requires the optional tkinterdnd2 package; if it isn't installed, the "Sfoglia" (Browse) button is still available.
Duplicate paths if two keys in the same preset point to the same folder, the path field turns red and a warning appears at the top — useful to spot a slip immediately.

Visualizza (Display) // which files to show

ON/OFF switches to include or exclude images, videos, PDFs and extension-less files (detected via magic bytes) from browsing. At the bottom, a field to add custom extensions to include (e.g. .heic, .arw, .cr2, .dng), comma-separated. Changes apply the next time a folder is loaded.

Tag // managing tags and Tag Groups

Two side-by-side columns. On the left, the Tag column: create, rename or delete a tag from the library's registry — a tag can now exist even before being applied to a file, not only "discovered" by using it. On the right, Gruppi Tag (Tag Groups): create, rename or delete a group, and a cloud to add or remove tags from the selected group's membership — purely organizational, used as a shortcut in Naviga's filter (one click adds every tag in the group to the filter). At the bottom, the preferred sort order for the tag cloud (alphabetical, recent use, or frequency).

Tasti (Keys) // shortcut reference

A scrollable, read-only list of every available keyboard shortcut, grouped by category — the same table at the bottom of this manual, but reachable inside the program without having to leave it.

Stream Deck // physical device

At the top of the tab, an ON/OFF switch disables the physical Stream Deck entirely — useful for using another program with the same device: once off, neither the program nor the autostart daemon touch the hardware anymore. The effect is immediate, no restart needed.

Below, configuration for the device, if connected: connection status, model and number of keys detected, brightness. The central part manages the idle-mode pages — tabs "Pag.1", "Pag.2" etc. (added with the "+ Pag." button, and removed automatically once empty), a grid mirroring the physical key layout, and an editor to assign an action to each selected key (open folder/app/URL, keyboard shortcut, mute/unmute, text, page change, one of the direct commands).

Info // language and information

Interface language selector (automatically reopens Settings translated after the change), the program's logo, and version/license information.

Privacy lets you pick folders that won't be shown or scanned in the browse window (Naviga) or in Timeline; in addition, every operation on the folders in this list is not recorded in History and so cannot be undone.

Folders on the "privacy" list are marked with a red border in Naviga and in Folder analysis, and any window showing images from those folders is given a red border too.

Deck window // on-screen keypad

Our best tool for managing presets: a floating, always-on-top, resizable keypad that mirrors on screen — clickable with the mouse — the same sorting grid as the Sidebar. Opens with D or P, or from the "Deck" button in the toolbar. Useful on a second monitor, or whenever the mouse is preferred to the keyboard. Saved destinations that aren't reachable (missing disk or folder) are shown with a grey background.

Up to 7 presets together

Each column shows a different preset, chosen from the dropdown at the top: handy for sorting into several groups of destinations without constantly switching the active preset.

Drag & drop folders

Just like in the Destinazioni tab, you can drag a folder from an external file manager straight onto a key to assign it as a destination — instant, without going through Settings.

Touch-friendly buttons

This control panel is optimized for quickly finding and managing destination keys — using a touchscreen is the best way to use it!

Reordering preset destinations: dragging one key onto another (even in a different column/preset) swaps the two destinations: label and path change places, while the key's number and color stay put. It's the fastest way to reorder a preset's folders, or to move one from a preset to another, without having to retype it in Settings.

Ratings & ColorLabel

Every file — photo, video or PDF — can have a rating from 0 to 5 stars and one or more colored labels, which aren't mutually exclusive.

Visible and editable everywhere it makes sense: under every thumbnail in Naviga and Timeline, in the enlarged preview panel, from the right-click menu, and from a dedicated overlay on the main image (Ctrl+F). Every change is reflected everywhere immediately, with no need to reload.

Filtering by rating in Naviga, the "Filtro *" button next to the sort controls opens a minimum-rating and color picker; in Timeline, the sidebar shows dedicated sections with counts.

Tags // free text tags and Tag Groups

Besides Rating and ColorLabel, every file can carry as many free-form text tags as you like — your own keywords, not a predefined list.

Tag window Ctrl+T

A cloud of existing tags, filterable by typing; a new tag is created with Enter. Follows navigation of the current file (arrow keys, toolbar buttons...) and works as a toggle: click to add or remove the tag from the file shown.

Multi-selection

From the right-click menu, "Tag..." entry: a tag is highlighted only if present on ALL selected files; clicking applies or removes it using the same "all-or-nothing" logic already used for stars and colors.

Clickable row

Below the grid, both in Naviga and in Timeline: applies a tag to the current selection without opening the dedicated window — "Tag" checkbox to hide it.

Tag Groups

Group related tags (Settings > Tag tab, see above) — for now mainly useful as a shortcut in Naviga's filter: one click adds every tag in the group at once.

Tag filter in Naviga the "Filtro *" button shows every tag in the library (not just the ones typed), Tag Groups as a shortcut, and uses "any match" (tags_any) logic across the chosen tags. The tag filter only exists in Naviga — in Timeline the tag row at the bottom is for applying tags, not for filtering the view.

Compare mode // previous/next side by side

"Confronta" button in the viewer, next to "Schermo intero" (Fullscreen) (or key W): places two smaller previews next to the main canvas — the previous file on the left, the next one on the right — which follow navigation on their own, with no need to go back for a quick before/after.
The Del key deletes the center image, asking for confirmation; Ctrl+Del instead trashes the file in the left column, without asking for confirmation.

View-only the two side previews have no right-click menu or commands of their own: they're only there to show what comes before and after without leaving the current file. Every command (rotate, crop, sort...) still acts only on the center image.

Physical Stream Deck // optional hardware control

Support for any Elgato Stream Deck model, in two modes (configurable from the "Stream Deck" tab in Settings, see above).

Preset mode

The physical keys mirror the software's active preset: same numbers 0-9, same colors, direct sorting from the device.

Idle mode

Configurable pages with free actions per key: open a folder, an application, a URL, a keyboard shortcut, mute/unmute, text.

Over 30 direct commands

Rotate, delete, zoom, send to an external editor and more — each assignable to a key with a customizable icon.

Reactive "Rating/Flag" buttons

A row of 5 colorlabels and a row of 5 stars, lit up or off based on the file currently open — click to apply or remove.

Background daemon

Keeps the physical deck active even while the program is closed, automatically handing control back when Image Sorter is opened.

ON/OFF switch

From Settings > Stream Deck: once off, neither the program nor the autostart daemon touch the physical device anymore — useful for using another piece of software with the same Stream Deck. Immediate effect, no restart needed.

Keyboard shortcuts // quick reference

The same list, always up to date, is also available inside the program in the Impostazioni > Tasti (Settings > Keys) tab.
