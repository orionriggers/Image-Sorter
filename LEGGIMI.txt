IMAGE SORTER v1.36
==================
Un programma per gestire, visualizzare e smistare immagini, video e PDF.

Versione        : 1.36
Linguaggio      : Python 3.8+
Interfaccia     : tkinter + Pillow
Piattaforma     : Linux (testato su Linux Mint / Ubuntu)

INSTALLAZIONE RAPIDA
--------------------
  bash installa.sh

  oppure manualmente:
    pip install Pillow send2trash pymupdf streamdeck --user
    pip install piexif reverse-geocode folium tkinterdnd2 --user
    pip install pillow-avif-plugin --user   (per file .avif)
    pip install pillow-heif --user          (per file .heic/.heif)

AVVIO
-----
  python3 image_sorter.py
  python3 image_sorter.py /percorso/immagine.jpg   (apre la cartella)
  python3 image_sorter.py --browser /percorso/     (apre con browser cartelle)

-----------------------
  Frecce             Naviga tra le immagini
  1-9, 0             Sposta nel preset attivo
  Ctrl+1-9,0         Copia nel preset attivo
  CANC               Cestina il file
  Z / X              Adatta / Originale
  + / -              Zoom in / out

  F                  Schermo intero
  H                  Mostra/nascondi intestazione
  C / A              Ruota 90° orario / antiorario
  K                  Ritaglia (Krop)
  I                  Overlay info EXIF

  O / B              Browser cartelle (Naviga) — apre/chiude

  Ctrl+Z             Annulla ultimo spostamento/crop
  Esc                Chiudi finestra aperta / esci

BARRA STRUMENTI PRINCIPALE
---------------------------
  Da sinistra a destra:
  [Play] | Naviga · Timeline · Impostazioni | Info EXIF | Originale · Estendi · - · + · Full Screen | Sidebar · S-Deck · Deck | Esci

  - [Play]: compare solo sui video
  - Info EXIF e Modifica EXIF: visibili solo per JPG/JPEG/TIFF/HEIC/HEIF
  - Separatori visivi tra gruppi funzionali
  - Naviga, Timeline, Impostazioni, Storico: lo stesso tasto (o la stessa
    scorciatoia) apre E chiude la relativa finestra, non serve più andare
    a cercare la X
  - S-Deck: cambia colore secondo lo stato del deck fisico — grigio non
    connesso, ciano connesso in idle, verde connesso in modalità preset.
    Tasto destro: apre le Impostazioni direttamente sulla tab Deck

NOVITÀ v1.27 → v1.28 (sessione di debug)
------------------------------------------
Nota: i manuali non erano stati aggiornati dalla v1.23 alla v1.27; questa
sezione riporta solo i fix verificati in questa sessione di debug sui file
alla versione 1.27.x. Le novità funzionali delle versioni intermedie
(1.24-1.27) non sono documentate qui perché non presenti nel materiale
disponibile in questa sessione.

BUG CORRETTI
  - timeline.py: la funzione build_map() usava "self.sorter" senza avere
    un'istanza self (è una funzione di modulo, non un metodo). Se folium
    non era installato, o non venivano trovate immagini con GPS, il
    programma andava in errore (NameError) invece di mostrare il messaggio
    previsto. Ora usa sempre messagebox, come corretto per una funzione
    standalone.
  - timeline.py: IMG_EXT non includeva ".heif" (era presente solo ".heic"),
    quindi i file HEIF non venivano riconosciuti come immagini in Timeline.
  - exif_editor.py: la funzione read_iptc_xmp() veniva chiamata ma non era
    mai stata definita da nessuna parte nel progetto. L'errore veniva
    silenziato da un except generico, per cui il tab IPTC/XMP mostrava
    sempre "Nessun dato IPTC/XMP trovato" anche quando i dati XMP erano
    presenti nel file. Aggiunta un'implementazione reale che legge il
    blocco XMP tramite Pillow (l'IPTC nativo resta vuoto: piexif non lo
    supporta e non era già una dipendenza del progetto).
  - image_sorter.py: nella finestra di errore mostrata all'avvio in caso di
    crash imprevisto, il testo usava "self.config" in un punto del codice
    dove "self" non esiste (siamo nel blocco except del lancio applicazione,
    prima che l'istanza ImageSorter esista). Questo causava un secondo
    errore che impediva la visualizzazione del messaggio (il log restava
    comunque scritto su disco). Ora la lingua viene rilevata dalla
    variabile d'ambiente LANG, come già fatto altrove nei fallback di avvio.
  - translations.py: alcune chiavi (btn_settings, btn_sidebar, btn_play,
    btn_quit, btn_fullscreen) erano duplicate sia in IT sia in EN. In
    inglese "btn_fullscreen" aveva due valori diversi ("Full Screen" e
    "Fullscreen"): il secondo, sovrascrivendo il primo, vinceva sempre.
    Rimosse le duplicazioni, mantenuto un solo valore coerente per chiave.

VERIFICHE ESEGUITE (nessun problema riscontrato)
  - Compilazione ok su tutti i file (py_compile + analisi AST)
  - Struttura LANG/SHORTCUTS coerente tra IT e EN (nessuna chiave mancante)
  - image_sorter_error.log vuoto (nessun crash registrato dall'utente)

  - Corretto un accumulo della larghezza minima della griglia: il reset

  - La rotella era legata due volte allo stesso pannello (scorrimento
    doppio ad ogni scatto) e con un binding globale all'intero
    programma: con Naviga aperta, la rotella mossa nel visualizzatore,
    in Timeline o nelle Impostazioni faceva scorrere anche la griglia
    delle miniature. Ora è un unico binding limitato alla sola finestra
  - Albero e vista elenco interrompono correttamente la propagazione

BROWSER "NAVIGA" — AREA SCORREVOLE
  - L'area scorrevole veniva calcolata con un metodo che in certe
    condizioni non restituisce alcun valore; in quel caso restava in
    vigore l'area della cartella precedente, permettendo di scorrere nel
    vuoto in una cartella vuota. Ora l'altezza è sempre calcolata in modo
    esplicito dal contenuto reale

BROWSER "NAVIGA" — MINIATURE DI FILE GRANDI
  - La generazione delle miniature avveniva sul thread principale, a
    lotti di 30 file: con video, PDF o immagini molto grandi il disegno
    della griglia restava bloccato per secondi. Ora sul thread
    principale si creano solo le celle e si riusano le miniature già in
    cache, mentre tutto ciò che richiede una decodifica viene generato
    in background e applicato appena pronto
  - Cambiando cartella, i risultati della cartella precedente vengono
    riconosciuti come superati e scartati
  - Corretto un blocco: un file illeggibile o corrotto mandava il
    caricamento della griglia in un ciclo infinito su quello stesso file

TIMELINE — STORICO E ANNULLAMENTO
  - Gli spostamenti fatti con i tasti numerici 1-9 su una selezione
    multipla non comparivano affatto nello Storico e non erano
    annullabili da lì (a differenza degli stessi spostamenti fatti dal
    menu contestuale). Ora sono registrati regolarmente
  - Un singolo file spostato viene registrato come voce singola e non
    più come "batch"
  - Le voci di tipo batch non hanno mai avuto la miniatura di anteprima,
    perché la si cercava in un percorso che per quelle voci è una
    cartella e non un file. Ora l'anteprima compare
  - L'annullamento di un batch poteva ripristinare il file sbagliato: se
    a destinazione esisteva già un file con lo stesso nome, quello
    spostato viene rinominato con un suffisso, e il ripristino andava a
    prendere il file preesistente. Ora ogni voce registra la
    destinazione reale di ciascun file
  - I file spariscono dalla vista solo se lo spostamento è davvero
    riuscito (prima sparivano anche in caso di errore, restando sul
    disco)

ANALISI CARTELLE
  - I formati HEIC/HEIF, AVIF e PNM/PBM/PGM/PPM finivano nella fetta
    "Altro" del grafico invece che in "Immagini", pur essendo gestiti
    come immagini in tutto il resto del programma

PULIZIA
